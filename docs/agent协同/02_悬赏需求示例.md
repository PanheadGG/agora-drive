# 悬赏需求示例

> 发起人都是普通人，想要的是大家网盘里**自己留存的原内容**（拍的照片、写的文档、存的表格），不是网上抄来的。

## 悬赏 R-01
发起人：喜欢做饭，想攒点家常做法
需求：家常菜做法素材
- 要的内容：自己拍的美食成品照片、手写菜谱照片、自己打的菜谱文档、记录做法的表格
- 文件类型：图片、Word、表格、PDF 都可以
- 时间：不限年份，近一两年的优先
- 不要：网上直接下载/复制的网红菜谱文章、外卖菜单截图、美食博主视频截图

## 悬赏 R-02
发起人：周末想周边爬山，找靠谱路线
需求：本地徒步/爬山路线素材
- 要的内容：自己拍的路线沿途照片（有岔路口、补给点、地标）、自己整理的路线文档/表格
- 文件类型：图片为主，Word/表格/PDF 辅助
- 不要：小红书、旅游网站下载的现成攻略、旅行社宣传图

## 悬赏 R-03
发起人：家里养猫，参考喂养经验
需求：家养猫咪日常记录素材
- 要的内容：自己记的喂养表格（体重、驱虫、换粮）、拍的猫的状态照片、文字记录
- 文件类型：表格、图片、文档
- 不要：宠物店/医院宣传、卖猫信息、收费单据照片

## 悬赏 R-04
发起人：平时爱看书，想看真实读后感
需求：个人读书笔记/读后感素材
- 要的内容：自己写的读后感想文档、摘抄笔记
- 文件类型：Word、文本、手写笔记照片
- 不要：电子书原文、网上复制的范文、教辅资料

## 悬赏 R-05
发起人：想了解日常通勤情况
需求：通勤情况记录素材
- 要的内容：自己记的通勤记录表格/文档、拍的通勤时间表照片
- 文件类型：表格、图片、文档
- 不要：含身份证/手机号/住址的信息、新闻报道、官方统计文件

---
### Agent 匹配规则
1. 一律先**解析真实内容**（图片识图+OCR、文档抽文字、表格看字段），再判断匹配。
2. 识别"用户自己留存的原内容" vs "网上搬运的"：后者直接排除。
3. 内容里解析出身份证/手机号/人脸/住址等敏感信息，直接标【高风险，不建议直接提交】。
4. 输出：悬赏编号｜匹配等级（高/中/低/不推荐）｜证据（解析到的内容片段）｜风险提示。
