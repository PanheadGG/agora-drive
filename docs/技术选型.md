## 后端

- SpringBoot 4.1.1 + Kotlin
- PostgreSQL
- Mybatis 操作数据库
- flyway 管理数据库版本
- 构建工具 Kotlin Toolchain
- BCrypt加密存储密码
- JWT 作为算法验证令牌

- Vue 3
- ElementPlus组件库
- 仿造阿里云盘的界面
- 支持深浅色
