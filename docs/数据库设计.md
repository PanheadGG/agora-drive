
# 1. user 用户表
| 字段名 | 字段类型 | 键 | 约束 | 备注 |
| ---- | ---- | ---- | ---- | ---- |
| id | BIGINT UNSIGNED | PK | AUTO_INCREMENT NOT NULL | 用户主键 |
| username | VARCHAR(64) | UK | NOT NULL | 用户名，唯一 |
| password | VARCHAR(128) | - | NOT NULL | 加密后的密码 |
| total_quota | BIGINT UNSIGNED | - | DEFAULT 10737418240 | 总配额(字节，默认10G) |
| used_size | BIGINT UNSIGNED | - | DEFAULT 0 | 已用空间(字节) |
| status | TINYINT | - | DEFAULT 1 | 0禁用，1正常 |
| created_at | DATETIME(3) | - | DEFAULT CURRENT_TIMESTAMP(3) | 创建时间 |
| updated_at | DATETIME(3) | - | DEFAULT CURRENT_TIMESTAMP(3) ON UPDATE CURRENT_TIMESTAMP(3) | 更新时间 |

# 2. file_meta 文件元数据表（完整文件，sha256 唯一）
| 字段名 | 字段类型 | 键 | 约束 | 备注 |
| ---- | ---- | ---- | ---- | ---- |
| id | BIGINT UNSIGNED | PK | AUTO_INCREMENT NOT NULL | 文件主键 |
| sha256 | VARCHAR(64) | UK | NOT NULL | 整个文件哈希，秒传判断+路径推演 |
| total_size | BIGINT UNSIGNED | - | NOT NULL | 文件总大小(字节) |
| created_at | DATETIME(3) | - | DEFAULT CURRENT_TIMESTAMP(3) | 创建时间 |

> 秒传：上传前算出 sha256，命中则直接建 `user_file` 引用，不重复落盘。

| is_recycle | TINYINT | IDX(联合) | DEFAULT 0 | 是否回收站 |

# 4. upload_task 分片上传任务表（断点续传）
| 字段名 | 字段类型 | 键 | 约束 | 备注 |
| ---- | ---- | ---- | ---- | ---- |
| id | BIGINT UNSIGNED | PK | AUTO_INCREMENT NOT NULL | 任务主键 |
| user_id | BIGINT UNSIGNED | IDX | NOT NULL | 上传用户 |
| task_id | VARCHAR(64) | UK | NOT NULL | 前端上传任务唯一ID |
| file_name | VARCHAR(255) | - | NOT NULL | 原始文件名 |
| total_size | BIGINT UNSIGNED | - | NOT NULL | 文件总大小 |
| total_chunk | INT UNSIGNED | - | NOT NULL | 总分片数 |
| sha256 | VARCHAR(64) | - | NULL | 完整文件hash，合并完成回填 |
| finished_chunk | INT UNSIGNED | - | DEFAULT 0 | 已上传分片数 |
| status | TINYINT | - | DEFAULT 0 | 0上传中，1完成，2过期取消 |
| expire_at | DATETIME(3) | IDX | NOT NULL | 任务过期时间 |
| created_at | DATETIME(3) | - | DEFAULT CURRENT_TIMESTAMP(3) | 创建时间 |
| updated_at | DATETIME(3) | - | DEFAULT CURRENT_TIMESTAMP(3) ON UPDATE CURRENT_TIMESTAMP(3) | 更新时间 |

## 存储路径推演（无需入库）
```
正式文件: {storage_root}/{sha256[0:2]}/{sha256[2:4]}/{sha256}     # 前4位分目录，防单目录过多
临时分片: {temp_root}/{task_id}/{chunk_index}                     # 分片上传临时目录，合并后删除
```

## 分片流程（合并后删除临时目录，写 file_meta）
```
分片上传 → {temp_root}/{task_id}/{0..n-1}
全部完成 → 按序合并 → 计算 sha256 → 写入 {storage_root}/xx/yy/{sha256}
        → 若 file_meta 已存在则秒传；否则 insert file_meta
        → 删临时目录，update user_file / used_size
```
